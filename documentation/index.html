CapitalForge Finance Documentation

CapitalForge Finance is an ultra-premium HTML5 template developed for commercial equipment financing brokerages, working capital advisors, and business loan facilitators.

Core Framework Bootstrap 5.3.3
JavaScript Vanilla JS (ES6+)
Micro-Animations GSAP 3.12+

Quick Setup

No build step or Node compilation is required. CapitalForge Finance is pure HTML5, CSS3, and Vanilla JavaScript.

  1. Unzip the template archive into your web server root or static directory.
  2. Open any .html file in any modern web browser or upload directly to your web hosting provider (Apache, Nginx, Vercel, Netlify, AWS S3, etc.).
  3. To customize brand typography or colors, edit assets/css/style.css.

Loan Calculator Engine

The interactive calculator located in assets/js/main.js implements the standard commercial amortization formula: 

// Standard Amortizing Formula
if (annualRate === 0) {
  monthlyPayment = P / n;
} else {
  const r = (annualRate / 100) / 12;
  const rateFactor = Math.pow(1 + r, n);
  monthlyPayment = P * (r * rateFactor) / (rateFactor - 1);
}

It automatically synchronizes range sliders, numeric input fields, preset chips ($50K, $150K, $500K, etc.), term pill selectors, visual breakdown share bars, and builds sample 12-month amortization previews.
