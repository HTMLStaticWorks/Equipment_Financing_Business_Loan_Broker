# CapitalForge Finance — Equipment Financing & Business Loan Broker HTML5 Template

**CapitalForge Finance** is an ultra-premium, production-ready website template engineered for commercial equipment financing brokerages, working capital advisors, and business funding intermediaries. Built strictly with modern web standards (HTML5, Bootstrap 5.3.3, CSS3, Vanilla JavaScript, and GSAP micro-animations), it features zero framework bloat and delivers high-conversion commercial finance aesthetics suitable for ThemeForest, TemplateMonster, and Creative Market.

---

## 🌟 Key Features

* **Multi-Theme Engine (Light & Dark Mode)**: Detects system preference via `prefers-color-scheme`, preserves selection across pages via `localStorage`, with accessible contrast and crystal-clear form fields.
* **Interactive Business Loan Calculator**: Standard monthly amortizing calculation engine with zero-interest edge cases, real-time input/slider synchronization, term pills (12–84 months), preset chips ($50K to $2M), visual principal vs. interest breakdown bar, and sample 12-month amortization schedule generator.
* **17+ Fully Linked HTML5 Pages**:
  * `index.html` — High-conversion commercial funding broker homepage.
  * `home-2.html` — Executive financial advisory & growth strategy homepage.
  * `financing.html` — Complete financing solutions directory.
  * `financing-details.html` — Master reusable financing detail blueprint.
  * `equipment-financing.html` — Hard asset leasing & procurement.
  * `equipment-loans.html` — Direct ownership secured equipment loans.
  * `working-capital.html` — Operational cash-flow smoothing & bulk purchasing.
  * `business-line-of-credit.html` — Revolving capital access on standby.
  * `commercial-financing.html` — Large-scale corporate debt facilities ($250K–$5M+).
  * `solutions.html` — Goal-oriented solutions (Start/Grow, Equip, Operate, Expand, Flex).
  * `funding-process.html` — 6-step funding journey timeline with clear regulatory disclosures.
  * `loan-calculator.html` — Dedicated financial calculator engine.
  * `about.html` — Brokerage philosophy, core values, and leadership showcase.
  * `contact.html` — Consultation inquiry form with interactive validation.
  * `login.html`, `signup.html`, `forgot-password.html` — Front-end auth UI demonstrations (No dashboard redirect).
  * `404.html` — Finance-themed error page.
  * `coming-soon.html` — Client portal announcement with live JavaScript countdown timer.
  * `documentation/index.html` — Developer & buyer documentation.
* **Responsive Sticky Navbar**:
  * Desktop dropdowns for Home, Financing, and Solutions.
  * Full-viewport mobile offcanvas drawer with nested collapsible accordion menus.
  * Keyboard navigation and `Escape` key listeners.
* **Design & Typography**:
  * Fonts: Google Fonts `Space Grotesk` (Headings) and `Inter` (Body & UI).
  * Curated commercial photography for construction, manufacturing, healthcare, logistics, dining, agriculture, and executive consultation.
  * Tabular figure formatting for financial numbers.
* **Compliance & Safety**:
  * Prominent disclaimers that estimates are illustrative and actual terms depend on independent lender criteria.
  * Fictional brokerage identity: CapitalForge Finance.

## 🚀 Quick Start

1. Open `index.html` in any modern web browser or launch a static local server:
   ```bash
   # Using Python 3 (if installed)
   python -m http.server 8000

   # Or using Node (if installed)
   npx serve .
   ```
2. Navigate to `http://localhost:8000` to preview the template.
